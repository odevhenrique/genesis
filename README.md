# O que é o projeto?

uma aplicação que ajuda ao leitor entender a passagem da biblica atraves de um estudo teologico, retornando o contexto que aquele texto foi escrito, em qual epoca e quem o escreveu, alem de ajudar ao usuario entender como pode aplicar isso em sua vida de forma prática.

# Objetivo educacional?

Incentivar o estudo das escrituras como palavra de Deus, considerando que ela é suficiente para ensinar qualquer pessoa sobre quem é Deus.
