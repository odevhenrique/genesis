## ADR-001: Usar Python + FastAPI no backend

- Contexto: desenvolver um banckend capaz se adptar a estrutura completa do projeto que envolver inteligencia artificial.
- Alternativas: py,ts e js.
- Decisão: Python é melhor para usar com analisa de dados pois ja vem com bibliotecas nativas que facilitam nesse processo.
- Preço que aceito pagar: aprender a desenvolver esse projeto do 0 sem copiar e colar codigo.
